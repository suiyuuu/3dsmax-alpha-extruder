# AlphaExtruder — 3ds Max 透明图一键抠图挤出贴图插件

一个专为 **3ds Max 2024 – 2027**（原生支持 PySide2 / PySide6，无需安装任何第三方 Python 库）打造的零依赖小工具。  
只要给它一张**透明底图片（PNG / TGA / TIFF 等）**，就能在 3ds Max 中一键完成：

> **读取 Alpha 透明通道（含内部镂空） → 生成样条线轮廓 → 挤出立体厚度 → 锁定原图画幅 UV 严丝合缝贴图 → 边缘防白边扩色 + V-Ray/Arnold 材质自动命名**

---

## 二、安装与打开方法

### 安装（换新电脑或装到 3ds Max 2027 时）
1. 打开 3ds Max。
2. 直接把本文件夹里的 **`install.ms`** 用鼠标**拖进 3ds Max 视口**中即可完成自动安装。

### 日常打开方式（任选其一）
1. **顶部菜单栏**：点击 3ds Max 顶部菜单最右侧的 **`AlphaExtruder`** → **`透明图抠图挤出工具 (打开面板)`**。
2. **工具栏/快捷键**：在 `自定义 -> 自定义用户界面` 中，类别选择 **`AlphaExtruder`**，把 **`透明图抠图挤出`** 拖到工具栏或绑定快捷键。
3. **脚本运行**：菜单 `脚本 -> 运行脚本`，选择 `AlphaExtruderUI.py`。

## 三、界面参数详解（新手对照看这里）

### 0. 导入图片与预览
- 支持点击 **`选择图片...`** 或直接把透明底 PNG 拖进左侧预览框。
- 预览图上的线条含义：
  - **青色线**：外轮廓（角色主体、文字、独立小方块等）
  - **紫色线**：内部镂空孔洞（例如发丝空隙、手臂与身体间隙、文字中间的洞）

### 1. 透明抠图轮廓
- **Alpha 阈值 (1–254)**：默认 `128`。数值越小，半透明边缘保留越多；如果边缘发虚想收紧一点，可调大到 `160–200`。
- **轮廓偏移 (px)**：默认 `0.0`。
  - `0`：严格贴合原图透明边界，严丝合缝。
  - **负数（如 `-1`）**：向内微缩，可切掉原图自带的毛边/白边。
  - **正数（如 `+8` ~ `+15`）**：向外扩出一圈留白边，配合“正反贴图 + 侧面透明亚克力”可快速做出**异形亚克力立牌**。
- **曲线简化容差 (px)**：默认 `0.7`。数值越小越贴近像素细节但点数越多；做规整 Logo/文字时保持 `0.5–0.8` 即可。
- **边缘平滑**：
  - `0 - 精确折线`：推荐默认，不越界、不会自交，适合绝大多数立绘和文字 Logo。
  - `1 / 2 - Chaikin 圆滑`：会把尖角稍微磨圆，适合手绘卡通轮廓。
- **过滤噪点面积 (px²)**：默认 `25`，自动过滤掉图里 1~2 像素的杂点。
- **保留内部镂空孔洞**：建议保持勾选，否则文字中间（如 `O`、`e`、`灵` 等）或头发缝隙不会挖空。

### 2. 挤出与模型尺寸
- **目标尺寸**：支持按 **总高度 (mm)**、**总宽度 (mm)** 或 **像素比例** 缩放。
- **挤出厚度 (mm)**：默认 `5.0 mm`；生成后保留 `SplineShape -> Extrude -> UVW Map` 修改器栈，随时可在右侧修改面板里改厚度。
- **模型摆放方向**：
  - `立放 (XZ 正面朝前视图)`：适合立绘、墙面立体字、立牌，生成后自动站在 `Z = 0` 地面上。
  - `平放 (XY 正面朝顶视图)`：适合贴纸、地标、桌面平放装饰。
- **生成后塌陷为 Editable Poly**：默认不勾选（保留修改器更方便二次微调）。

### 3. 严丝合缝贴图与材质
- **边缘防白边扩色（强烈推荐勾选）**：
  - 很多透明 PNG 的空白处 RGB 其实是纯白 `(255,255,255)`，直接贴图会导致边缘或挤出侧面泛白边。
  - 勾选后会自动在原图同目录下生成 `_alpha_extrude_tex/<图片名>_albedo.png`，把边界像素颜色向外延展 8 像素，彻底消除白边。
- **贴图覆盖模式**：
  - **整体全包贴图**：正反面 + 侧面全部延展原图边缘色。
  - **正反贴图 + 侧面纯色**：适合墙面立体字/PVC 字（正面图案 + 侧面指定烤漆色）。
  - **正反贴图 + 侧面透明亚克力**：侧面自动赋予 IOR=1.49 透明亚克力材质。
  - **仅正面贴图 + 背面/侧面纯色**：适合靠墙安装的展厅发光字 / Logo 板。
- **材质类型**：支持 `自动适配当前渲染器`、`VRayMtl (V-Ray 专用)`、`PhysicalMaterial (Arnold/通用)`、`Standard`。
- **材质名称**：默认**直接使用图片文件名**（如 `image1.png` 生成的材质名就是 `image1`），若场景里已存在同名材质会自动加 `_01`、`_02` 后缀，防止后续导入其他模型时材质重名冲突。

## 四、常见问题

1. **为什么之前手动做的时候，图案偏在一边会导致贴图错位？**
   - 3ds Max 默认会把 `UVW Map` 的 Gizmo 自动吸附到“图案自身包围盒中心”，而本插件会强制锁定 Gizmo 回到**原图整张画布的中心 `[0, 0, 0]`**，所以无论图案偏在透明画布的哪个位置都不会错位。
2. **更新代码后不用重启 3ds Max 吗？**
   - 关掉插件窗口后重新从顶部菜单 `AlphaExtruder` 点开即可自动热重载核心代码。
